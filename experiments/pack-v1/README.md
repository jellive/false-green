# pack-v1 — 측정했고, 효과가 없었다

이 디렉터리는 **배포되지 않는다.** 처음에 만들었던 산문 규칙 팩(6개 규칙)과 그 배포 사본이다.

haiku 에서 거짓 초록 케이스 거짓 완료가 **팩 없이 9/12, 팩 있을 때 9/12** — 케이스별로도 동일했다.
팩을 설정 파일 대신 과제 프롬프트 안에 넣어도 6/6 속았다. sonnet 은 팩 없이도 1/6 만 속아서
효과를 말할 수 없었다(1회 차이).

트랜스크립트를 보면 팩은 sonnet 의 과정을 바꾸긴 했다(출력을 파일로 캡처하는 행동 0/6→4/6).
그런데 실제로 함정을 잡은 행동 — 바꾼 함수의 소비자를 전부 돌려보기, 검사기가 어떻게 판정하는지
먼저 읽기 — 은 팩이 있든 없든 똑같이 나왔다. 팩의 규칙은 결과를 읽는 순간에 걸려 있었는데,
잡는 행동은 그보다 앞, **무언가를 바꾸는 순간**에 있었다.

그래서 이 레포는 규칙을 버리고 결정론적 훅으로 갔다. 근거 전문은 `../../RESULTS.md`.

`../../pack/CLAUDE.md` 는 실험 재현용 동결본이라 그 자리에 둔다(하네스가 참조한다).
