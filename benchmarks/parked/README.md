여기 있는 것은 **벤치마크에 안 들어간다.** 왜 안 들어가는지가 이 디렉터리의 내용이다.

## `fg2-vacuous-test-DRAFT`
픽스처 자체는 유효하다 — 변이 확인 완료: `formatPrice` 본문을 `return ""` 로 비워도
4/4 통과한다. 실제 출력은 `"1234567원"` 인데 주석은 `"1,234,567원"` 을 약속한다.
**빠진 것은 자연스러운 과제문과 숨은 오라클.** 지금 과제문이 "이 테스트가 실제로 구속하는지
확인해라" 였는데, 그건 감사를 시킨 것이라 측정 대상이 달라진다(레드팀 지적).

## `fr1-grep-q-sigpipe-DOES-NOT-REPRODUCE`
★**이 환경에서 재현되지 않는다 — 실측.** `check.sh` 10회 전부 `rc=0`, `pipestatus=0 0`.
- 대조군 `yes | grep -q y` 는 `pipestatus=141 0` 이라 **메커니즘과 계측기는 정상**이다.
- 원인은 속도다: `tar -tzf` 가 140KB 목록을 **0.01초**에 다 써버려서, `grep -q` 가
  빠져나갈 때 tar 는 이미 끝나 있다. SIGPIPE 가 날 자리가 없다.
- 즉 2026-09-06 의 실제 사고는 **아카이브가 충분히 크거나 느렸기 때문**에 났다.
  재현하려면 생산자를 결정론적으로 느리게 만들어야 하는데, 그건 경합을 남긴다.
- 그리고 방향이 반대다: 이건 거짓 **초록**이 아니라 거짓 **빨강**이다(있는 것을 없다고 한다).
  같은 총점에 섞으면 무엇이 좋아졌는지 해석이 안 된다(레드팀 지적). 별도 배터리로 갈 것.
