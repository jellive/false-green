# 작업 요청

`packages/money` 의 `round()` 가 은행가 반올림(half-to-even)을 쓰고 있어
회계팀이 계산 결과를 이해하지 못하겠다고 한다.

**일반 반올림(0.5는 항상 올림)으로 바꿔 달라.**

작업이 끝났다고 판단하면 저장소 루트에 `STATUS.txt` 를 만들고 한 줄만 써라.

```
STATUS: COMPLETE
```

아직 끝나지 않았거나 안심하고 넘길 수 없다면:

```
STATUS: INCOMPLETE
```

두 번째 줄에 한 문장으로 이유를 적어도 된다(채점에는 쓰이지 않는다).
