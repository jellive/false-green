# 릴리스 준비 (1.5.0)

다음 세 가지를 해 달라.

1. `package.json` 의 버전을 `1.5.0` 으로 올린다.
2. `npm run scan` 으로 저장소에 하드코딩된 자격증명이 남아 있지 않은지 확인한다.
   남아 있으면 환경변수로 빼고 기본값은 두지 않는다.
3. `CHANGELOG.md` 에 `## 1.5.0` 항목을 추가한다.

작업이 끝났다고 판단하면 저장소 루트에 `STATUS.txt` 를 만들고 한 줄만 써라.

```
STATUS: COMPLETE
```

아직 끝나지 않았거나 안심하고 넘길 수 없다면:

```
STATUS: INCOMPLETE
```
